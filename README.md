#### **Better Search** is a client-side mod that enhances search bars with support for mistyped searches and multiple languages.

Searches affect the Creative Inventory, Recipe Book, and even the chat. Each of these can be individually enabled or disabled through a fully customizable, intuitive, and easy-to-use menu accessed by pressing the **mod custom menu hotkey:**

<font size="6"><kbd>Alt</kbd> + <kbd>O</kbd></font>
<br>
<sub><i>(That is the letter O, not the number 0!)</i></sub>



Below are some useful settings that make this mod stand out from similar alternatives:
- **Full search support for any mod**
- Better Search system is also compatible with: [JEI](https://modrinth.com/mod/jei/versions), [REI](https://modrinth.com/mod/rei), [NEI](https://www.curseforge.com/minecraft/mc-mods/not-enough-items-1-8/files/2755792) and [EMI](https://modrinth.com/mod/emi)
- Fully configurable multi-language support
- Fully configurable fuzzy search system
- Vanilla-faithful interface
- Pre-configured for almost any language
